# Safety SOS App

Android app jo emergency me ek tap ya phone shake karne par saved contact ko
live Google Maps location ke saath SMS bhejti hai.

## Features
- Emergency contact save karna
- SOS button se live location SMS
- Phone shake karne par automatic SOS
- Contact ko seedha call karna

## Tech Stack
Kotlin, Jetpack Compose, Fused Location Provider API, SmsManager, SensorManager
